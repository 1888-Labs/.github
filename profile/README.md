# 1888 Labs

**Building open infrastructure for verifiable, distributed, and intelligent systems.**

1888 Labs is an independent research and engineering lab exploring how modern software can become more open, trustworthy, and independently verifiable.

We build open-source libraries, protocols, infrastructure, developer tools, and experimental systems across distributed computing, cryptography, AI infrastructure, blockchain, and systems engineering.

Our work starts with a simple question:

> How can we build systems that users and developers can verify instead of simply trust?

## What We Work On

Our work generally falls across four areas:

### Verifiable Systems

Infrastructure that makes data, computation, and system state independently verifiable.

Examples include:

- authenticated data structures
- cryptographic proofs
- verifiable datasets
- state verification
- proof-carrying data
- integrity and provenance systems

### Distributed Systems

Software designed to operate across machines, networks, and trust boundaries.

We explore:

- distributed protocols
- consensus systems
- networking
- storage systems
- blockchain infrastructure
- peer-to-peer architectures
- fault-tolerant systems

### Intelligent Systems Infrastructure

Infrastructure for software agents and AI-powered systems.

Areas of interest include:

- agent permissions
- agent identity
- verifiable agent actions
- AI infrastructure
- tool execution
- agent coordination
- provenance and auditability

### Developer Infrastructure

Reusable tools developers can build larger systems with.

This includes:

- Rust libraries
- SDKs
- APIs
- runtimes
- developer tooling
- protocol implementations
- infrastructure components

## How We Build

Our work usually follows a simple path:

**Research → Prototype → Open Source → Infrastructure**

Some projects stay as experiments.

Some become reusable libraries.

Some grow into larger infrastructure projects.

And occasionally, a project may evolve into an independent product or company.

## Projects

### MerkleForge

A Rust framework for authenticated data structures and cryptographic proof verification.

MerkleForge provides implementations of multiple Merkle tree constructions and tools for generating portable proofs that can be independently verified.

### ProofStream

Experimental infrastructure for turning indexed datasets into independently verifiable datasets using cryptographic commitments and Merkle proofs.

### Mandate

Experimental infrastructure for verifiable permissions, policies, and execution boundaries between software agents and external systems.

More projects coming soon.

## Principles

### Open by Default

Research prototypes, infrastructure, and developer tools should be open whenever possible.

### Verify, Don't Assume

Systems should expose enough information for users and developers to independently verify important claims.

### Infrastructure Over Hype

We care more about useful primitives and working systems than trends or labels.

### Build to Learn

Research should produce working implementations, and implementations should generate better research questions.

### Small Primitives, Large Systems

Strong infrastructure often begins with small, reusable components.
