# 1888 Labs

**Building open infrastructure for verifiable, distributed, and intelligent systems.**

1888 Labs is an independent research and engineering lab. We build open-source libraries, protocols, and developer tools across distributed systems, cryptography, blockchain, and AI infrastructure, starting from one question:

> How can we build systems that users and developers can verify instead of simply trust?

## What We Work On

- **Verifiable systems**: authenticated data structures, cryptographic proofs, and provenance.
- **Distributed systems**: protocols, consensus, storage, and blockchain infrastructure.
- **Intelligent systems**: identity, permissions, and auditability for AI agents.
- **Developer infrastructure**: Rust and TypeScript libraries, SDKs, and protocol implementations.
